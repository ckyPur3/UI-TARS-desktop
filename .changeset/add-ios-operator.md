Initial release of iOS operator for UI-TARS Desktop. This adds comprehensive support for controlling iPhone and iPad devices using natural language commands.

Features:
- Screen capture via libimobiledevice
- Touch and swipe simulation using WebDriverAgent
- Text input support
- Hardware button simulation (home, lock, volume controls)
- Multiple device support with device selection
- Comprehensive documentation and examples
